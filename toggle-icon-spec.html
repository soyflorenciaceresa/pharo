Toggle Icon

Spec del component set Toggle Icon (página Toggle Icon, nodo 657:39): 2 variantes de State (Inactive y Active), con el color ligado a un token.

Component set 657:392 variantesTamaño: 20 × 20 pxActualizado 29/09/2026

·Vista general (interactiva)

1Qué es

Toggle Icon es un botón de estrella que permite marcar o desmarcar un maestro o proceso como favorito.

2Cuándo usarlo

  • Para marcar como favorito un maestro o proceso desde su pantalla principal, junto al título (por ejemplo, Buque en /buques).
  • Para que ese maestro o proceso aparezca en el Acceso rápido de la Home de su módulo.
  • Para cualquier control de dos estados de tipo “guardar / quitar de mi lista”, donde el resultado se ve de inmediato en otro lugar.

3Cuándo no usarlo

  • No usar en pantallas administrativas de Main (Usuarios, Perfiles, Empresas) → no llevan favorito; el favorito es un concepto de módulos de negocio.
  • No usar para activar o desactivar una opción de un formulario → usar Checkbox.
  • No usar para ejecutar una acción (guardar, exportar, eliminar) → usar Button con iconOnly.
  • No usar como estado de un registro dentro de una tabla (activo / inactivo) → usar Badge.
  • No usar dentro de formularios de alta, edición o vista → el favorito se marca desde la pantalla principal del maestro.

4Variantes

Una sola propiedad de variante (State). No hay jerarquías ni tamaños.

VarianteVistaPara qué sirveEjemplo de uso
State=InactiveEstrella vacía: el elemento no es favorito. Acción disponible: agregar.“Buque” sin marcar; etiqueta “Agregar a favoritos”.
State=ActiveEstrella rellena: el elemento es favorito. Acción disponible: quitar.“Buque” marcado; etiqueta “Quitar de favoritos”.

Tamaños: solo existe uno (20 × 20 px). El color es siempre color/yellow/500 en ambas variantes: cambia la forma (contorno o relleno), no el color.

No hay propiedades de texto, boolean ni instance swap. El ícono no es una instancia: es un vector propio del componente.

Combinaciones inválidas o sin efecto

  • No hay combinaciones inválidas: una sola propiedad con dos valores.
  • En código, sin onToggle el botón se dibuja pero no hace nada; LayoutMaestroDataGrid ni lo renderiza en ese caso.

[Supuesto — validar] Nombre y valores de State (Inactive/Active) elegidos al crear el componente; confirmar con el equipo si prefieren Favorite=True/False.

8Reglas de uso

✅ Hacer

  • Ubicarlo a la derecha del título de la pantalla, con 4 px de separación (--spacing-xs).
  • Usar un solo Toggle Icon por pantalla.
  • Mostrarlo solo en la pantalla principal de un maestro o proceso de un módulo de negocio.
  • Mantener el estado fuera del componente (controlado): la Home del módulo lee el mismo estado.
  • Usar el color color/yellow/500 (--color-yellow) siempre, sin importar el estado.
  • Usar instancias del component set y cambiar solo State.

❌ No hacer

  • Mostrarlo en Usuarios, Perfiles o Empresas (pantallas de Main).
  • Cambiar el color entre marcado y sin marcar: el cambio es solo de forma.
  • Agregar texto o contador junto a la estrella sin definirlo antes con diseño.
  • Usarlo como interruptor de una opción de formulario.
  • Desacoplar la instancia para cambiar tamaño o color.
  • Dibujar una estrella suelta en lugar de usar el componente.

Orden de foco: un solo punto de foco. El foco no se mueve al alternar el estado (queda en el botón).

Lector de pantalla

  • Elemento nativo <button type="button"> con aria-pressed ("true" en Active).
  • Nombre accesible hoy: “Agregar a favoritos” (Inactive) y “Quitar de favoritos” (Active). Se lee: “Quitar de favoritos, botón, presionado”.
  • El ícono es decorativo: debe llevar aria-hidden="true".

[Supuesto — validar] Combinar aria-pressed con una etiqueta que cambia puede confundir: el lector anuncia una acción y un estado a la vez. Recomendado: una etiqueta fija (“Favorito”) con aria-pressed, o cambiar la etiqueta sin aria-pressed.

10Componentes átomo relacionados

Usa internamente

  • Icon (en código: bi-star / bi-star-fill, 20 px). En Figma el ícono está dibujado como vector propio, porque no hay estrellas en la página Icon. [Supuesto — validar] Reemplazar por una instancia cuando existan.

Hermanos / alternativos

  • Checkbox: opción de sí/no dentro de un formulario, con label y valor que se envía al guardar.
  • Button (iconOnly): ejecuta una acción inmediata; no mantiene estado activado.
  • Badge: muestra un estado de solo lectura; no es interactivo.
