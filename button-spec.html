Button

01Qué es

Button es un control que ejecuta una acción inmediata —guardar, crear, confirmar o avanzar un paso— cuando la persona lo activa con clic, toque o teclado.

02Cuándo usarlo

  • Para enviar o guardar un formulario, por ejemplo Guardar operación al pie de un Form Container → Solid.
  • Para la acción principal de un listado de Maestros, por ejemplo + Nuevo cliente en la cabecera de la página → Left Icon.
  • Para la acción secundaria que acompaña a la principal: Cancelar junto a Guardar, o Exportar junto a Nueva operación → Outline.
  • Para acciones de baja jerarquía dentro de una card, un panel o una fila de Data grid: Ver detalle, Limpiar filtros → Text.
  • Para avanzar en un flujo de varios pasos: Siguiente >, Continuar > → Right Icon.
  • Para acciones compactas en toolbars o filas de tabla cuyo ícono se entiende sin texto (agregar, editar, cerrar), siempre con tooltip → Icon Only.

03Cuándo no usarlo

  • No usar para navegar a otra página o URL → usar un Link, un ítem de Sidebar o Breadcrumb.
  • No usar para activar o desactivar una opción → usar Switch o Checkbox.
  • No usar para elegir entre vistas u opciones excluyentes → usar Tabs, Radio o Select.
  • No usar dos Solid en la misma vista → dejar un solo Solid y pasar el resto a Outline o Text.
  • No usar Icon Only con íconos que no son universales (p. ej. Procesos, Tipos de turnos) → usar Left Icon con label.
  • No usar para moverse entre páginas de resultados → usar Pagination.
  • No usar Solid azul para acciones destructivas (Eliminar, Anular) → por ahora, Outline + modal de confirmación; falta una variante Danger. Supuesto — validar

06Anatomía

Label 1 2 3 4 5 Label 6

Composición ilustrativa: en Figma ninguna variante tiene ambos íconos a la vez.

  1. Contenedor — obligatorio. Capa: el propio componente (Variant=…, State=…). Auto layout horizontal, padding spacing/padding-button-x (16) × spacing/padding-button-y (8), gap spacing/gap-button (4), radio radius/button (8). En Icon Only el padding es 8 en los cuatro lados.
  2. Ícono leading — opcional (solo Left Icon e Icon Only). Capa: Leading Icon. Instancia 16×16 de la página Icon; color igual al del texto.
  3. Label — obligatorio, salvo en Icon Only. Capa: Label. Estilo de texto Button/Label MD (Inter Semi Bold 14 / 120%).
  4. Ícono trailing — opcional (solo Right Icon). Capa: Trailing Icon. Instancia 16×16.
  5. Borde — opcional (solo Outline). Stroke interior de border/action-secondary-width (1 px).
  6. Anillo de foco — solo en State=Focus. Stroke exterior de border/width/focus (2 px) con color/border/focus; en Outline es una sombra spread 2 px del mismo color.

Combinaciones inválidas o sin efecto

  • Icon y Trailing Icon no hacen nada en Solid, Outline y Text.
  • Variant=Icon Only sin nombre accesible definido en el handoff (tooltip + aria-label).
  • Label vacío en cualquier variante que no sea Icon Only.
  • Íconos de otro tamaño que 16×16 en Icon / Trailing Icon: rompen el alto del botón.

08Reglas de uso

✅ Hacer

  • Escribir el label con verbo en infinitivo + objeto: “Guardar cambios”, “Crear cliente”.
  • Usar entre 1 y 3 palabras, en una sola línea.
  • Usar mayúscula solo en la primera letra (“Nueva operación”).
  • Máximo un Solid por vista o por sección independiente.
  • En formularios, alinear el grupo a la derecha con la acción principal a la derecha de la secundaria. Supuesto — validar
  • Separar botones de un mismo grupo con un token de spacing, no con un valor fijo.
  • Acompañar todo Icon Only con un tooltip que repita la acción.
  • Cambiar íconos con la propiedad Icon / Trailing Icon, usando la librería Icon.

❌ No hacer

  • Escribir labels en MAYÚSCULAS o con puntos finales.
  • Usar labels genéricos como “Aceptar” u “OK” cuando se puede nombrar la acción.
  • Poner dos Solid uno al lado del otro.
  • Usar un Text como único CTA de un formulario.
  • Desacoplar la instancia para cambiar colores o padding.
  • Dejar un botón en Disabled sin explicar qué falta para habilitarlo.
  • Dibujar botones sueltos (frames) en lugar de usar instancias de Button.
  • Agregar un ícono solo como decoración, sin relación con la acción.

09Notas de accesibilidad

Patrón WAI-ARIA APG: Button. Implementar con el elemento nativo <button type="button"> (o type="submit" en formularios).

Teclado

TeclaAcción
Tab / Shift+TabMueve el foco al botón siguiente / anterior según el orden del DOM.
EnterActiva el botón.
EspacioActiva el botón al soltar la tecla.
  • El orden de foco sigue el orden visual (izquierda → derecha, arriba → abajo).
  • El botón no mueve el foco por sí mismo. Si abre un modal, el foco va al modal y vuelve al botón al cerrarlo.
  • Con disabled nativo el botón sale del orden de tabulación. Si tiene que seguir siendo descubrible (p. ej. para leer un tooltip que explica por qué), usar aria-disabled="true" e ignorar la activación.

Lector de pantalla

  • Rol: button (nativo).
  • Nombre accesible: el texto del Label. En Icon Only, aria-label obligatorio (“Agregar fila”).
  • Íconos: aria-hidden="true" en Leading Icon y Trailing Icon: son decorativos cuando hay label.
  • Anuncios: Default → “Guardar, botón”. Disabled → “Guardar, botón, no disponible”. Si abre un menú: aria-haspopup="menu" + aria-expanded → “Acciones, botón, contraído”.

10Componentes átomo relacionados

Usa internamente

  • Íconos de la página Icon: PlusLg y ChevronRight por defecto; admite cualquier ícono 16×16.
  • Estilo de texto Button/Label MD.

Hermanos / alternativos

  • Link: para navegar; el botón ejecuta acciones.
  • Pagination: para moverse entre páginas de resultados.
  • Tabs: para cambiar de vista dentro de la misma página.
  • Sidebar / Breadcrumb: para la navegación global.

Pendientes

  • Tamaños: solo existe Medium. Hay tokens …/lg (spacing/padding-button-x/lg, Button/Label LG): ¿agregamos Size=Large?
  • Loading: el componente anterior lo tenía y este no.
  • Danger: no hay variante para acciones destructivas; existe el token color/danger/default.
  • Íconos + jerarquía: las variantes con ícono solo existen en Solid. Propuesta: separar en Style (Solid/Outline/Text) × Icon (None/Left/Right/Only).
  • Altos distintos: Outline mide 35 px (el borde suma al layout), Icon Only 32 px y el resto 33 px. Conviene unificar.
  • Foco sobre Solid: el anillo tiene 1,42:1 contra el fondo del botón. Evaluar un gap blanco de 2 px entre botón y anillo.
  • Spread del foco en Outline: el color está ligado a token, pero el spread de 2 px no.
  • Instance swap: Icon y Trailing Icon no tienen valores preferidos configurados.
  • Migración: la página del Button anterior se eliminó; revisar si quedan instancias rotas en otras páginas (TopBar, Form Container, layouts).
  • Orden en formularios: confirmar si la primaria va a la derecha.
